# pokemon-card-game

ポケモンカードゲームを、ブラウザで遊べるようにしたものです。今は CPU と対戦できます。スマホは横向きで遊びます。

**遊ぶ:** https://123yoshidandy.github.io/pokemon-card-game/

## ルール

公式の基本ルールに沿っています。

- デッキは60枚。手札7枚から始め、たねポケモンがなければ引き直す（相手はその回数まで追加で引ける）
- バトル場に1匹、ベンチに5匹まで。サイドは6枚
- 自分の番：山札を1枚引き、ベンチに出す・進化・エネルギー（1回）・トレーナーズ（サポートとスタジアムは1回）・特性・にげる（1回）を好きな順に行い、ワザを使うと番が終わる
- 先攻の最初の番は、ワザとサポートを使えない。最初の自分の番と、出したばかりのポケモンは進化できない
- 弱点は×2、抵抗力は−30。テラスタルのポケモンは、ベンチにいる間ワザのダメージを受けない
- 特殊状態（どく・やけど・ねむり・マヒ・こんらん）と、番の終わりのポケモンチェック
- サイドを取り切る・相手の場にポケモンがいなくなる・相手が山札を引けなくなる、のどれかで勝ち。ex がきぜつすると、サイドは2枚

## デッキ

構築済みのデッキが2つあります（`public/js/decks.js`）。開始画面で自分のデッキを選び、CPU はもう一方を使います。

- **リザードンex**：ヒトカゲ・リザード・リザードンex、ガーディ・ウインディ、基本炎エネルギー
- **ミライドンex**：ミライドンex、ピカチュウ・ライチュウ、コイル・レアコイル、基本雷エネルギー

トレーナーズは、博士の研究・ナンジャモ・ジャッジマン・ボスの指令・ネストボール・ハイパーボール・ふしぎなアメ・ポケモンいれかえ・キズぐすり・エネルギー回収・エレキジェネレーター・ゆうきのおまもり・ボウルタウンです。

カードの名前とワザは実在のカードに合わせていますが、HP・ダメージ・ワザのエネルギーなどの数値には、実物と違うものがあります。絵は仮のもの（タイプの色と記号）です。

## 操作

- 手札をタップして使う。エネルギー・進化・どうぐは、光ったポケモンをタップしてつける
- バトルポケモンをタップすると、ワザ・にげるを選べる。特性のあるポケモンは、タップして特性を使う
- カードを長押しすると説明が出る。トラッシュは、右の欄の「トラッシュ」をタップすると見られる

## 開発

必要なもの：Node.js 22 以上、Python 3（画面を手元で配信するため）

```bash
npm install
npm test                                   # ルール・CPU のテスト
python3 -m http.server 8080 --directory public   # http://localhost:8080/ で遊ぶ
```

### 構成

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ゲームの進行。DOM に依存しない。操作はすべて `applyCommand` を通し、記録から `Game.replay` で再現できる |
| `public/js/card-data.js` | カードの定義（データと効果の関数） |
| `public/js/decks.js` | 構築済みデッキ |
| `public/js/game-view.js` | そのプレイヤーから見てよい情報だけのビュー（相手の手札・山札・サイドは枚数だけ） |
| `public/js/cpu-player.js` | CPU。人間と同じ操作を返す。乱数は使わない |
| `public/js/game-controller.js` | CPU 対戦のコントローラー（`getView()` と `send()`） |
| `public/js/ui/` | 画面（盤面・手札・ダイアログ・カードの描き方） |
| `public/js/main.js` | 起動と画面の切り替え |
