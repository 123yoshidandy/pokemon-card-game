# pokemon-card-game

ポケモンカードゲームを、ブラウザで遊べるようにしたものです。CPU との対戦と、友人とのオンライン対戦ができます。スマホは横向きで遊びます。

**遊ぶ:** https://123yoshidandy.github.io/pokemon-card-game/

## ルール

公式の基本ルールに沿っています。

- デッキは60枚。手札7枚から始め、たねポケモンがなければ引き直す（相手はその回数まで追加で引ける）
- バトル場に1匹、ベンチに5匹まで。サイドは6枚
- 自分の番：山札を1枚引き、ベンチに出す・進化・エネルギー（1回）・トレーナーズ（サポートとスタジアムは1回）・特性・にげる（1回）を好きな順に行い、ワザを使うと番が終わる
- 先攻の最初の番は、ワザとサポートを使えない。最初の自分の番と、出したばかりのポケモンは進化できない
- 弱点は×2、抵抗力は−30。テラスタルのポケモンは、ベンチにいる間ワザのダメージを受けない
- 特殊状態（どく・やけど・ねむり・マヒ・こんらん）と、番の終わりのポケモンチェック
- サイドを取り切る・相手の場にポケモンがいなくなる・相手が山札を引けなくなる、のどれかで勝ち。ex がきぜつすると、サイドは2枚（メガシンカex は3枚）
- 進化は名前でつながる（別の版のたねポケモンからも進化できる）
- ACE SPEC はデッキに1枚まで

## カードとレギュレーション

カードは、今のスタンダードレギュレーション（マーク H・I・J）の実在カードです。データは [TCGdex](https://tcgdex.dev) の日本のカードから取り、`public/js/cards/catalog.js` に入れています（約2,000種類）。絵は仮のもの（タイプの色と記号）です。

- 同じ名前・同じ効果のカードは、収録パックが違っても1種類として扱います（スタンダードに再録があれば、古いマークの版も使える、という公式の扱いに合わせています）。トレーナーズと特殊エネルギーは、名前が同じなら同じカードです。文は一番新しい版のもの、ID は一番古い版の番号（例：`M6-010`）です
- 使えるマークは `public/js/regulation.js` の `STANDARD_MARKS` で決めています。レギュレーションが変わったら、ここを直します
- 基本エネルギーはマークがなく、いつでも使えます

**効果が動くカードだけを使えます。** 今は、1,916種類すべて（ポケモン1,652・トレーナーズ239・エネルギー25）が動きます（`node tools/card-coverage.mjs` で数が、`node tools/list-unsupported.mjs` でまだ動かないカードがわかります）。

- ワザの効果は、文を決まった形に読み替えて動かします（`public/js/cards/attack-effects.js`。例：「コインを1回投げオモテなら、30ダメージ追加。」）。読み替えられないものは `attack-overrides*.js` に、カードごとに書きます
- 特性は `abilities/`、トレーナーズは `trainers/` と `trainer-effects.js`、特殊エネルギーは `energy-effects.js` に、名前で書きます。いるだけで働く効果は、本体が場のカードに問い合わせる「フック」で書きます（書き方は `public/js/cards/HOOKS.md`）
- テラスタル・古代・未来・ACE SPEC の印は TCGdex のデータにないので、Limitless TCG の検索結果から補っています（`tools/data/limitless-tags.json`）
- TCGdex の文から記号が抜けているカードは、Limitless TCG のページの文で直しています（`tools/data/text-fixes.json`）
- 「相手の効果を受けない」（ばけがくれ など）のために、本体は効果の出どころ（だれの、どのカードの効果か）を覚えていて、相手のポケモンを変える関数がそれを確かめます（`HOOKS.md` の「効果の出どころと『効果を受けない』」）
- 割り切っているところ：
  - リトライバッジで投げなおせるのは、ワザのダメージの前に投げたコインだけ
  - 危ない廃墟・どっきりおとしは、本体の関数（ベンチに出す・山札からトラッシュする）を通ったときだけ働く
  - 化石を場からトラッシュする操作は、特性のボタンとして出す
  - TCGdex にないパック（MF・MEE・M6a など）にしかないカードは入っていない

カードのデータを取り直すとき（新しいパックが出たときなど）：

```bash
node tools/fetch-cards.mjs     # TCGdex から取って tools/data/tcgdex-ja/ に保存（保存済みのセットは飛ばす。--refresh で取り直す）
node tools/build-cards.mjs     # public/js/cards/catalog.js を作り直す
node tools/card-coverage.mjs   # 動くカードの数
node tools/list-unsupported.mjs attacks|abilities|trainers   # まだ動かないカードの一覧
```

## デッキ

構築済みのデッキが2つあります（`public/js/decks.js`）。開始画面とロビーで自分のデッキを選びます。CPU は、自分のデッキとタイプの違う構築済みデッキを使います。

- **メガリザードンYex**：ヒトカゲから、ふしぎなアメでメガリザードンYex に進化させ、プロージョンY で相手のポケモンを1匹選んで倒す。ウインディが2匹目の攻め手
- **ミライドンex**：ミライドンex とライチュウで攻め、後半はジバコイル。ピカチュウとコイルは、なかよしポフィンで出せる

「デッキ構築」で、自分のデッキを作れます。新しく作るか、構築済みデッキをコピーして編集します。カードは名前（ひらがなでもよい）と、公式のカード検索の詳しい条件にならった項目ごとのプルダウンでしぼれます（ポケモンはタイプ・進化・特別なルール・古代/未来・特性・HP・弱点・抵抗力・にげる・マーク、トレーナーズは種類（サポート・グッズ・ポケモンのどうぐ・スタジアム）・ACE SPEC・古代/未来・マーク、エネルギーは種類（基本・特殊）・ACE SPEC・マーク）。項目ごとに1つ選び、選んだ項目すべてに合うカードが出ます（`public/js/card-filter.js`）。60枚・スタンダードのカードだけ・同じ名前のカードは4枚まで（基本エネルギーは何枚でも）・ACE SPEC は1枚まで・たねポケモンが1枚以上、がそろったデッキだけを対戦に使えます。作ったデッキはブラウザに保存されます（`public/js/deck-store.js`。前の版のカードIDは、読み込むときに今のIDに読み替えます）。

## 操作

- 手札をタップして使う。エネルギー・進化・どうぐは、光ったポケモンをタップしてつける
- バトルポケモンをタップすると、ワザ・にげるを選べる。特性のあるポケモンは、タップして特性を使う
- カードを長押しすると説明が出る。トラッシュは、右の欄の「トラッシュ」をタップすると見られる

### オンライン対戦
1. 開始画面で「オンライン対戦」を押し、名前を入れて「部屋を作る」を押す
2. 「招待」で友人にURLを送る（友人は開いて名前を入れ、「参加する」を押す。部屋番号（数字4桁）でも参加できる）。CPU を相手にすることもできる
3. ロビーでデッキを選び、部屋を作った人（ホスト）が「開始」を押す
4. 決着したら、ホストの「もう一度」で再戦できる。「部屋に戻る」は誰でも押せる

接続が切れても、同じ端末で開き直せば同じ席に戻れます。対戦中に部屋を出ると、その人の番は CPU が代わりに打ちます。

## 開発

必要なもの：Node.js 22 以上、Python 3（画面を手元で配信するため）、AWS SAM CLI（サーバーをデプロイするとき）

```bash
npm install
npm test                                   # ルール・CPU・オンライン対戦のテスト
python3 -m http.server 8080 --directory public   # http://localhost:8080/ で遊ぶ
npm run dev:server                         # 手元のオンライン対戦のサーバー（ws://localhost:8787。PORT で変えられる）
npm run deploy:server                      # AWS にデプロイ（スタック pokemon-card-game-online）
```

オンライン対戦の部屋の仕組みは、共通部品 netplay-kit を `server/netplay/` と `public/js/netplay/` にコピーして使っています（直接は直さない）。ゲームの中身は `server/src/game-definition.js` です。サーバーは操作の記録だけを保存し、操作のたびに記録から対戦を再現します。デッキは対戦の最初に、各プレイヤーが送ります。

### 構成

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ゲームの進行。DOM に依存しない。操作はすべて `applyCommand` を通し、記録から `Game.replay` で再現できる |
| `public/js/card-data.js` | カードの定義（データに効果をつないで組み立てる。効果が動くかの印 `supported` もつける） |
| `public/js/cards/` | カードのデータ（`catalog.js`。作ったもので、手で直さない）と効果（ワザ・特性・トレーナーズ） |
| `tools/` | カードのデータの取得・作り直し・数え上げ |
| `public/js/decks.js` | 構築済みデッキ |
| `public/js/game-view.js` | そのプレイヤーから見てよい情報だけのビュー（相手の手札・山札・サイドは枚数だけ） |
| `public/js/cpu-player.js` | CPU。人間と同じ操作を返す。乱数は使わない |
| `public/js/game-controller.js` | CPU 対戦のコントローラー（`getView()` と `send()`） |
| `public/js/ui/` | 画面（盤面・手札・ダイアログ・カードの描き方） |
| `public/js/main.js` | 起動と画面の切り替え |
